# 利用ガイド（非開発者向け）

## できること

対象チャンネルのメッセージに**国旗の絵文字リアクション**を付けると、その言語への翻訳が**あなただけに表示**されます（他の人には見えません）。

## 使い方

1. 翻訳したいメッセージにマウスを乗せ、絵文字リアクションを付けます。
2. 下表の国旗を選びます。
3. しばらくすると、メッセージのスレッド or チャンネルに「あなただけに表示されています」という形で翻訳結果が出ます。

| 付ける国旗                | 翻訳される言語 |
| ------------------------- | -------------- |
| 🇻🇳 ベトナム               | ベトナム語     |
| 🇯🇵 日本                   | 日本語         |
| 🇺🇸 アメリカ / 🇬🇧 イギリス | 英語           |

### 対応していない言語の国旗を押すと

🇨🇳🇰🇷🇫🇷🇩🇪🇪🇸🇮🇹🇧🇷🇷🇺🇹🇭 など、主要国の国旗も認識します。ただし上表以外の言語はまだ翻訳に対応していないため、その場合は「翻訳をご希望ですか？現在このbotではご指定の言語への翻訳に対応しておりません。」というお知らせがその言語であなただけに表示されます（翻訳は行われません）。対応言語を増やしたい場合は管理者に依頼してください。

## よくある質問

- **翻訳結果が他の人に見えますか？**
  見えません。リアクションを押したあなただけに表示されます。

- **翻訳結果が消えました。**
  「あなただけに表示」のメッセージは、画面を再読み込みしたり時間が経つと消えます。仕様です。もう一度国旗を付け直せば再表示されます。

- **反応しません。**
  - 対象チャンネル以外では動きません。
  - 対応している国旗（上表）以外では動きません。
  - 画像や添付だけで本文テキストが無いメッセージは翻訳できません。
  - Botがそのチャンネルに参加していない場合は動きません（管理者に連絡してください）。

- **他の言語も追加できますか？**
  追加できます。管理者（開発者）に依頼してください。
